INSTALLATION

便捷三步安装到 Chrome / Edge

遵循 Manifest V3 标准，无任何广告，开箱即用。

01

下载最新构建包

从 GitHub Releases 下载最新的 qrcode-extension-v1.1.2.zip 离线压缩包并解压。

02

打开扩展管理面板

在 Chrome 浏览器地址栏中输入 chrome://extensions，并开启右上角的【开发者模式】。

03

加载已解压的扩展程序

点击【加载已解压的扩展程序】，选中解压出来的 dist 或 src 目录，即刻体验！
